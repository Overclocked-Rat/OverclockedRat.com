Notes

  • Click pages to select them, or type a range like 1-3, 7. Extracting always outputs pages in document order.
  • "Split every page" ignores the selection above — it always produces one PDF per page for the whole document, zipped together.
  • Password-protected PDFs can't be opened — you'll get a clear message rather than a silent failure. Remove the password first, then split.
  • Thumbnails render in this tab, so very large documents may take a moment. If rendering fails for some reason, typing a page range still works.
